Before installation

インストール前に確認すること

Windowsで「WindowsによってPCが保護されました」「認識されないアプリ」と表示される場合があります。Microsoft Defender SmartScreenは配布ファイルや発行元の評価を確認するため、新しいアプリやバージョンで警告が出ることがあります。

まず配布元とファイルを確認してください

公式配布元は EbiSenbei / cotaska-site のGitHub Releases です。取得したバージョンのリリースを開き、Assetsのファイル名とダウンロードしたファイル名が一致するか確認してください。現行のインストーラー名は Cotaska-<バージョン>-win-x64.exe です。通常の導入ではEXEを選びます。.blockmap と latest.yml は自動更新用で、手動で開く必要はありません。

SHA-256が掲載されている場合は、同じバージョン・同じファイル名の値と照合してください。値が異なる場合や、配布元・確認用の値が分からない場合は実行を中止し、公式リリースの情報を確認してください。ハッシュの一致は公開されたファイルとの一致を示すもので、安全性そのものを保証するものではありません。

WindowsでSHA-256を確認する方法

PowerShellを開き、次のファイルパスをダウンロードしたEXEの実際の保存先に置き換えて実行します。表示された Hash を、同じファイルの公開されたSHA-256と比較してください。英字の大文字・小文字は区別しません。

Get-FileHash -LiteralPath 'C:\保存先\インストーラー名.exe' -Algorithm SHA256

配布元を確認しても警告が消えるとは限りません。確認できない場合は実行を中止してください。Windowsの保護機能を無効にする必要はありません。会社などの管理されたPCでは、管理者の方針に従ってください。

Before using AI chat

AIチャットを使う前に

通常のタスク管理は起動後すぐに使えます。AIチャットには、対応するAIサービスの利用環境と認証が必要です。

1

AIサービスを準備

利用するAIサービス側で認証を済ませます。Cotaskaは認証情報そのものを保存しません。

2

作業フォルダを選択

Cotaskaの設定画面で、AIが参照・作業するフォルダを明示的に指定します。

3

送信範囲を確認

入力内容、参照ファイル、モデル、実行権限を確認してからAIへ送信します。

料金について

Cotaska本体は無料です。AIチャットで利用するOpenAI、Anthropic、Amazon Bedrockなどの契約・利用枠・料金はCotaskaとは別で、選択した連携先の提供条件が適用されます。

データと通信について

タスクはローカルのMarkdownファイルとして保存されます。AIチャット利用時は、入力内容や選択した参照情報が連携先のAIサービスへ送信されます。CotaskaはOpenAI APIキー、Codexのアクセストークン、認証ファイルの内容を保存しません。
